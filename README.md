# Red Ball Mini (Browser-Spiel)

Ein einfaches 2D-Spiel im Browser mit HTML5 Canvas und JavaScript.

## 🎮 Steuerung

- **J** = Links
- **L** = Rechts
- **I** = Springen

(Diese Tasten kannst du in `game.js` ändern)

## 📦 Inhalt

- `index.html` – Die Hauptseite mit dem Canvas
- `game.js` – Der Spielcode
- `README.md` – Diese Datei
